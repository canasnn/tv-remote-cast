# Security Policy

## Reporting a vulnerability

Please do **not** report security problems in public issues. Use GitHub's private
vulnerability reporting instead: open the repository's **Security** tab and choose
**Report a vulnerability** (https://github.com/canasnn/tv-remote-cast/security/advisories/new).

Include a description, steps to reproduce and the app/receiver versions.

## Please keep private data out of reports

- Never post API keys, keystores, passwords or tokens (including an OpenSubtitles key).
- Don't post local IP or MAC addresses, pairing data or receiver tokens.
- Remove such details from logs before attaching them.
